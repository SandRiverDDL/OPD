## 5. Interpretation and limitations

- 训练期间 top-16 overlap 从 0.7394 上升到 0.8533，advantage magnitude
  和 grad norm 同时下降，表现出明显的蒸馏收敛趋势。
- 该 run 的 step80 AIME25 `avg@16=30.83%`，只能作为短程实验结果；
  不能与 strict baseline 的 step220 直接组成同一条训练曲线。
- 由于 prompt batch size、训练时长和数据处理路径与 strict baseline
  不完全相同，不能把差异归因于单一字段。
