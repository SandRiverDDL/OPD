## 4. Training diagnostics

### 4.1 指标口径

训练日志中的：

```text
val-topk/overlap_ratio
val-topk/adv_only_stu
```

虽然带有 `val-` 前缀，但不是独立 validation 指标。它们是在当前
global step 刚生成的训练 rollout batch 上计算，并在该 step 统一记录。

本 run 每个 global step nominally 包含：

```text
64 prompts × 4 responses = 256 rollout responses
```

`critic/advantages/abs_mean` 是当前训练 batch 中非零 token-level
distillation advantage 的绝对值平均。当前 `token_reward_direct` 配置下，
advantage 直接来自 token-level distillation reward，而不是额外的 GAE。

| 220 | 0.9236 | -0.0017 | 0.0048 | 0.12 | 5889 | 26.9% |

这些指标不是每一步严格单调，因为：

- 每步使用不同的 prompt 和 student rollout；
- 当前配置 `data.shuffle=False`；
- 不同数据区间的难度、语言和 response length 不同。

但从区间趋势看，student/teacher top-16 overlap 增大、
distillation advantage 缩小、actor gradient norm 下降，整体符合
token-level distillation 收敛预期。

### 4.3 Length behavior

训练 batch 的 response length 不是严格单调下降，但 early steps 大量
response 撞到 `MAX_RESP_LENGTH=7168`，后期 clip ratio 通常显著下降。

独立 AIME25 评测使用更长的 `max_tokens=31744`，其平均输出长度为：

| Model/checkpoint | 平均输出长度 |
|---|---:|
| Base student | 15111.63 |
| step20 | 12869.79 |
| step40 | 10748.87 |
| step60 | 9835.20 |
| step80 | 8560.35 |
| step120 | 8150.37 |
| step160 | 8302.29 |
| step200 | 8508.62 |
| step220 | 8340.54 |
| Teacher | 9076.95 |

这说明模型不仅提高了 AIME25 `avg@16`，也逐渐减少了初始 student
中的超长/重复 reasoning。当前没有证据表明这是显式 length reward；
更可能是 student 学到了 teacher 的推理和停止分布。

## 6. Interpretation

### Supported conclusions

- 在统一 AIME25 长输出评测口径下，step20–220 的整体趋势从 25.00%
  上升到 35.83%；
- 当前已评测 checkpoint 中，step220 的 `avg@16` 最高；
- 训练内部的 overlap、advantage magnitude 和 gradient norm 呈现
  一致的蒸馏收敛趋势；
- 独立 AIME25 eval 同时观察到平均 response length 从 base student
  的约15.1k 降至 step220 的约8.3k。

### Interpretation boundary

- AIME25 只有30题，step200→step220 的小幅提升不能单独视为稳定趋势；
- `val-topk/*` 是训练 batch 诊断，不是固定 validation；
- `data.shuffle=False` 使局部曲线可能受到数据顺序影响；
- 该 run 尚未提供 `fp32 + N_RESPONSES=1` 的严格消融，因此不能
  定量分离 dtype 与 response 数量的贡献；
- step220 与 teacher 的0.21个百分点差距不具有足够统计证据支持
  “student 已等价于 teacher”的结论。

## 7. Recommended follow-up

若要研究 `N_RESPONSES` 的单独影响，建议从本 run 复制，只改变：
